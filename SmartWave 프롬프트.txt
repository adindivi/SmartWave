◦ StandardScaler 자동 적용 후 학습

다운로드 방법:

import requests

url = 'https://huggingface.co/datasets/stdt1/MIMII_pump_datasets_16kHz_RMS_10s_V2/resolve/main/mel_nfft1024_hl512_nmels64_hann/train-00000-of-00002.parquet'

r = requests.get(url, timeout=300, stream=True)

with open('mimii_real/train_part1.parquet', 'wb') as f:

for chunk in r.iter_content(1024*1024): f.write(chunk)



데이터 구조:

• label=1: 정상 (3881개), label=0: 이상 (531개) ←역전 주의!

• data 컬럼: list of shape (1, 64, 313) mel spectrogram

• data[0]: array(64, 313) → np.array(list(data[0])) 로 변환



임베딩 방법 (mel_stats 128-dim):

def get_emb(data_field):

mel= np.array(list(data_field[0]), dtype=np.float32) # (64, 313)

return np.concatenate([np.mean(mel,1), np.std(mel,1)]) # (128,)



최적화 설정:

• 전처리: StandardScaler (scaler_mean, scaler_scale 저장 필수)

• 학습: 정상 100개 (SNR별 균형: -6dB, 0dB, 6dB 각 33개)

• OCSVM: gamma=0.001, nu=0.02 (grid search 최적값)

◦ JSON 파싱 (scaler_mean, scaler_scale, support_vectors, dual_coef, rho, gamma)

◦ preprocess(x): (x - scaler_mean) / scaler_scale

◦ compute(x, params): Σ dual_coef[i] × exp(-gamma × ||x-sv[i]||²) - rho

◦ anomalyScore(score): score≥0 → 0~40점(정상), score<0 → 41~100점(이상)

◦ score≥0 → 정상, score<0 → 이상

embedding_dim, embedding_mode,

scaler_mean (배열), scaler_scale (배열) ← Android 필수

metrics.f1, metrics.auc[Android OCSVM 판별 수식]

xScaled[i] = (x[i] - scaler_mean[i]) / scaler_scale[i]

f(x) = Σᵢ dual_coef[i] × exp(-gamma × ||xScaled - sv[i]||²) - rho

f(x) ≥ 0 → 정상 / f(x) < 0 → 이상[주요 다운로드 링크]

[주요 함정 모음]

1. torch CPU 전용 설치: pip install torch==2.4.1+cpu --index-url .../whl/cpu

(CUDA 버전 설치 시 c10_cuda.dll 충돌)

2. MIMII label 역전: label=1=정상, label=0=이상 (이 HF 데이터셋 기준)

3.MIMII data 접근: data[0] → np.array(list(data[0])) 필요 (dtype 혼재)

3. rho 부호: rho = float(-ocsvm.offset_[0]) ← 반드시 음수 처리

4. gamma 기본값: 527-dim이면 0.001, 128-dim이면 0.1~0.5

5. ONNX opset=14, ir_version=8 (onnxruntime 1.20 호환)

6. Unsqueeze: opset13+ 에서 axes는 별도 input tensor로 전달

7. panns_cnn10_industrial.tflite: 커스텀 바이너리 포맷 (표준 TFLite 아님)
