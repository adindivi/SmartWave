======================================================================
[SmartWave] 트랜스포머 (시간 맥락) 도입 타당성 검증 보고서
======================================================================

1. 실험 목적
----------------------------------------------------------------------
현재 SmartWave는 10초 분량의 오디오 전체를 하나의 527차원 벡터(CNN10)로 압축한 후 OCSVM(이상 탐지) 모델에 통과시킵니다.
이 방식은 빠르지만 오디오의 '시간적 흐름(Temporal Context)' 정보가 소실된다는 단점이 있습니다.
이를 보완하기 위해 10초 오디오를 1초씩 자른 뒤, 트랜스포머(Transformer) 모델을 통해 시간 맥락을 학습시킬 경우 성능 향상이 있는지 검증합니다.


2. 실험 방법론 (1단계 - 자기지도학습)
----------------------------------------------------------------------
정상 데이터만 존재하는 실제 산업 현장의 특성을 반영하여, 정상 데이터만을 활용한 훈련을 진행했습니다.

  • 데이터셋: 정상 모터 소리 1,200개 / 비정상 모터 소리 100개
  • 학습 방식 (Masked Reconstruction): 
      - 정상 오디오를 1초 단위로 자름 (10초당 19조각 추출)
      - 트랜스포머에 입력 시 임의로 조각의 30%를 가림 (Masking)
      - 트랜스포머가 전후 맥락을 파악해 가려진 원래 소리 특징을 복원해내도록 30 Epoch 학습
  • 평가 방식: Baseline 모델(단일 CNN)과 학습된 트랜스포머 모델 각각 OCSVM을 학습시킨 후 정상/불량 점수 비교


3. 최종 평가 지표 (결과)
----------------------------------------------------------------------
Metric                                  Baseline     Trained Transformer
----------------------------------------------------------------------
정상 오디오 점수 평균 (Normal Mean)       3.8281             3.5432
정상 오디오 최하 점수 (Normal Min)       -9.0710            -6.7012  (개선됨: 뭉침)
비정상 오디오 점수 평균 (Abnormal Mean)  -32.9286           -35.3972  (개선됨: 멀어짐)
정상-비정상 간 점수 차이 (Score Gap)     36.7567            38.9404
정상 판별 정확도 (Normal Accuracy)       89.7%              90.0%
불량 탐지율 (Abnormal Detection Rate)   100.0%             100.0%


4. 결과 분석 및 시사점
----------------------------------------------------------------------
✅ Score Gap Change: +5.9% 증가
✅ Normal Accuracy Change: +0.3% 향상 (오알람 감소)

[결론 1] 트랜스포머의 시간 맥락 학습은 효과가 있다.
랜덤 가중치 상태에서는 정상 데이터가 흩어져 정확도가 떨어지는 문제가 있었으나, 정상 데이터 1,200개로 자기지도학습(Masked)을 수행한 결과, 정상 데이터를 촘촘하게 뭉치게(Min 점수 상승) 하면서 동시에 불량을 더 멀리 밀어내는(Mean 점수 하락) 이상적인 결과를 얻었습니다.

[결론 2] 실무 적용 가이드
트랜스포머를 적용하면 연산량(10초당 1회 추출 -> 19회 추출)이 증가하여 추출 속도가 느려진다는 단점이 있습니다.
따라서, 현재 Baseline 모델이 실전(MIMII 데이터)에서 완벽한 성능을 보인다면 현재 구조를 유지하는 것이 최적입니다. 
하지만 추후 정상/불량 간의 차이가 미세하여 Baseline의 성능이 한계에 부딪힐 때, '트랜스포머' 카드를 통해 정확도와 분리도를 한 단계 더 끌어올릴 수 있음을 기술적으로 증명했습니다.

* 실험 후 학습된 트랜스포머 가중치는 'transformer_weights.pt' 파일로 보존되었습니다.
